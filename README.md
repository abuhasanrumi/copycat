# Copycat

A fast, lightweight clipboard manager for macOS. It lives in your menu bar, remembers everything you copy, and pops up a shelf of cards with `⇧⌘V`.

## Features

- **Clipboard shelf** – a full-width, frosted shelf with a card per clip, colored by the app it came from.
- **Smart cards** – text, links (with page title and preview image), images, files, colors, and code with syntax highlighting and language detection.
- **Search everything** – including text inside screenshots (on-device OCR).
- **Pinboards** – organize reusable clips into named pinboards; drag cards onto them.
- **Paste As** – pretty/minify JSON, camelCase, snake_case, kebab-case, Base64, URL encode/decode, sort lines, and more.
- **Privacy aware** – ignores password managers, blurs clips that look like secrets, and lets you ignore any app.
- **Quick Look** – press `Space` for a large preview; drag cards into other apps.

## Shortcuts

| Key | Action |
| --- | --- |
| `⇧⌘V` | Open / close the shelf |
| `← →` | Move between cards |
| `Return` / double-click | Paste |
| `⌘1`–`⌘9` | Paste the nth card |
| `Space` | Preview |
| `⌘P` | Pin to / unpin from a pinboard |
| `Tab` / `⇧Tab` | Switch Clipboard / pinboards |
| `⌫` | Delete the selected card |
| `Esc` | Clear search, then close |

## Install

Download the DMG, drag Copycat to Applications, and open it. The build isn't notarized, so the first time use right-click → Open, or run:

```sh
xattr -dr com.apple.quarantine /Applications/Copycat.app
```

To paste directly into other apps, allow Copycat under **System Settings → Privacy & Security → Accessibility**. Without it the clip is copied and you press `⌘V` yourself.

## Build from source

Requires macOS 13+ and the Xcode command line tools.

```sh
./build.sh run     # build Copycat.app (universal) and launch it
./make-dmg.sh      # build dist/Copycat-<version>.dmg
```

The app icon is generated by `scripts/make-icon.swift`.
